## CAD Model

This repository includes a 3D model of the photogrammetry rig exported in the STEP (.step) format.

### File:
- `photogrammetry_rig.step`

### Description:
This is a complete assembly model of the rig used for automated image capture. It was originally created in SolidWorks and exported to STEP format for universal compatibility.


### Scale:
- Units: millimeters
- The model is exported at 1:1 scale
